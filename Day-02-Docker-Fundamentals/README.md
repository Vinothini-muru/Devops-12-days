# 1. Docker Registry

A Docker Registry is a storage system used to store Docker images.

Docker images can be stored in either:

- Public repositories
- Private repositories

Docker Hub is a popular public Docker registry provided for storing
and sharing Docker images.

---

# 2. Docker Hub

Docker Hub is a cloud-based registry for Docker images.

It allows users to:

- Store Docker images
- Pull images
- Push images
- Share images
- Maintain public or private repositories

Docker Hub can be used as a central location for Docker images.

---

# 3. Why Use Docker Hub?

Docker Hub can be useful for:

- Sharing Docker images
- Storing images
- Pulling images from a remote registry
- Integrating image storage into the development workflow
- Using images across different environments
